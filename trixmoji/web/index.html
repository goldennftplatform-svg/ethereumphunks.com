How to test / what this proves
  1. As Seller, deposit a piece. Mine five blocks.
  2. Set a price and list it. Switch to Buyer and buy. Check the new owner and seller/creator credits.
  3. For another piece, deposit and start an auction. Bid as Buyer, then outbid as Bidder (at least 5% higher).
  4. Advance time, settle the auction, then withdraw refunded bids and seller proceeds.

This sandbox executes real Solidity on a disposable local EVM. Ethscriptions ownership is modeled from transfer events here; it is not a live mainnet indexer test. A production deployment needs a trusted indexer-verification signer, contract review, and end-to-end transfer verification.

No private keys, seed phrases, browser-wallet approvals, or real ETH are needed. Restarting the server resets this sandbox.
